# Enemy sprite sheets

Generated with built-in ImageGen using user-provided pixel-art references. Original generated PNGs preserved without raster edits; Canvas selects frames using measured source rectangles. RGBA 1122 x 1402, 4 columns x 5 rows, 20 poses per character.

Rows: idle A / idle B / hurt / death; up; down; left; right. Attack rows contain windup A, windup B, strike, recovery. Wraith horizontal rows are mapped in reverse, and knight horizontal columns are reordered in the renderer to follow the actual painted poses. See app.js for measured transparent gutters and mapping.
